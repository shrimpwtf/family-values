# Source and attribution

This skill distils **"Family Values"** by Benji Taylor, published 8 July 2024:
https://benji.org/family-values

[Family](https://family.co/) is a self-custody crypto wallet for iOS. The essay describes the principles behind its feel. In the author's words, it is "not a technical post or tutorial" but an account of "how we made something complex feel welcoming."

The principles and examples belong to the author and the Family team. This package restates them as actionable rules and checklists for design and engineering work. Wording that appears in quotation marks in the references is taken from the essay.

## Example index (rule → Family example)

| Rule | Family example |
|---|---|
| Gradual revelation | Fundamentals up front, everything else appearing as it becomes relevant; onboarding with many paths |
| Tray emerges from its context | Swap approval unfolding from the swap interface, with the first-use tutorial blended in |
| Consecutive trays differ in height | Content rewritten so each step in a sequence changes height |
| Tray theme follows context | Dark trays inside dark-themed flows |
| Map the journey | Onboarding card stack showing where each path leads |
| Directional motion | Tab switches moving left or right with the tapped tab |
| Animate small details | The chevron changing shape between multi-step screens |
| Text morph with shared letters | Continue → Confirm; wallet-count button labels |
| Persistent elements travel | Wallet cards moving between screens; partial updates to empty-state text |
| Cause and effect | Amount carried into confirmation; pending spinner moving to the activity tab; speed-up spinner moving to the pending tray |
| Animate reorganisation | Wallet addresses grouping themselves by seed phrase |
| Motion feels faster | Animated price charts (contrasted with Cash App's static charts) |
| Even polish | "A fancy restaurant with a dirty bathroom" (quip credited to Paco) |
| Subtle delight on frequent actions | Commas shifting during amount entry; over-balance easter egg |
| Medium delight | Trash-can tumble and sound; reorder stacking (inspired by Things); stealth-mode shimmer; chart arrow flip |
| High delight on rare moments | Wallet-creation animation; backup confetti |
| Hidden-in-plain-sight easter egg | QR code ripple and sequin swipe |
| Guiding first use | Animated arrow in the browser's empty state |
